How to Update Fire Data

All fire data is stored directly in this HTML file. To update, open index.html on GitHub, click ✏️ edit, use Ctrl+F to find the department, update the numbers, and commit.

  1. Visit zone2photo.com and note new fires by department and month
  2. Open GitHub repo → index.html → ✏️ Edit
  3. Press Ctrl+F, search for the department name (e.g. 720 Hempstead)
  4. Update the 12-number monthly array for the correct year
  5. Commit changes — site updates in ~60 seconds
