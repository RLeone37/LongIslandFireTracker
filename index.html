How to Update Fire Data

All data is embedded in index.html. To update: open GitHub → click index.html → ✏️ Edit → Ctrl+F to find the department → update the monthly array → Commit.

  1. Visit zone2photo.com and note new fires
  2. Open GitHub → index.html → ✏️ Edit
  3. Ctrl+F → search department name (e.g. 720 Hempstead)
  4. Update the 12-number monthly array for the year
  5. Commit — site updates in ~60 seconds
