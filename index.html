🔒 Update Data

How to Update

Edit fires.json on GitHub. Find the department, update the 12-number monthly array, and update metadata.last_updated to the last data update date.

  1. GitHub repo → fires.json → ✏️ Edit
  2. Ctrl+F → search dept name, such as 720 Hempstead
  3. Update the array — Jan first, Dec last
  4. Update last_updated if the data date changed
  5. Commit — site updates in about a minute
