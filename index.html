How to Update Fire Data

Fire data is stored in data/fires.json in this GitHub repository. To add new fire counts:

  1. Visit zone2photo.com/Working-Fire-Lists/ and note new fires
  2. Open your GitHub repository → data/fires.json
  3. Click the ✏️ pencil (Edit) icon
  4. Find the year + department, update the monthly array (12 numbers)
  5. Click Commit changes — site updates in ~60 seconds

Quick Entry Preview Tool

Build the JSON snippet below, then paste it into GitHub.

JSON Format Reference

12 numbers per department, one per month (Jan=0, Dec=11).

"2025": {
  "120 Floral Park": [1, 0, 0, 2, 0, 1, 0, 0, 0, 0, 0, 0],
  //                  Jan Feb Mar Apr May Jun Jul Aug Sep Oct Nov Dec
  "160 Mineola":     [0, 0, 1, 0, 0, 0, 2, 0, 0, 1, 0, 0]
}
